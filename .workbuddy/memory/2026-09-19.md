# 2026-09-19

## 桌面分区管家（DesktopOrganizer）v1.0 完成

**需求**：Windows 桌面分区工具，能在桌面上划分多个分区框，把文件拖进不同分区归类。

**技术选型（用户确认）**：
- C# WPF (.NET 8)，非 Electron / Python
- 悬浮窗方案（可显隐、不占任务栏），非嵌入桌面底层
- 拖入 = 真实移动文件到分区绑定文件夹，非快捷方式映射

**已实现**：分区 CRUD、拖动/缩放/折叠、吸附、跨分区拖拽、系统 Shell 真实图标提取、
全局热键 Ctrl+Alt+D、托盘菜单、开机自启（注册表 Run）、明暗主题、四种排序、
文件重命名/打开/回收站（SHFileOperation，走系统回收站）、分区文件夹丢失可一键重建。

**关键构建参数（踩过坑，别再试错）**：
- 自包含 + PublishSingleFile + IncludeNativeLibrariesForSelfExtract=true + EnableCompressionInSingleFile=true → **63MB 真单文件**
- 不开压缩是 138MB；开 PublishReadyToRun 会涨到 146MB，默认关掉
- Mac 上可交叉编译 WPF：需要 `<EnableWindowsTargeting>true</EnableWindowsTargeting>`，
  .NET SDK 装在 `~/.dotnet`（用官方 dotnet-install.sh 装的，无 brew）
- WPF + WinForms 同时启用时，`ImplicitUsings` 必须 disable，否则 Button/Application 类型歧义
- 切换 BaseIntermediateOutputPath 会让旧 obj/ 下的 .g.cs 被当成源码重复编译（CS0111），
  要验证真实体积请复制纯净源码到 /tmp 构建，不要在项目目录里折腾

**验证状态**：`dotnet build` 0 error / 0 warning；自包含单文件发布成功（63MB，PE32+ x86-64）。
产物已放 `dist/DesktopOrganizer-独立版.exe`。注意：Mac 上只能验证编译，**运行时行为未实测**。

**待办 / 风险**：首次在真实 Windows 上运行需确认——拖拽落点、DPI 缩放下的坐标换算、
图标提取、Win+D 时的窗口层级。
